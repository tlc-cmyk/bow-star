# 弓弦星

用弓拉《一閃一閃》——一隻喺瀏覽器即玩、以手機直立為主嘅小提琴弓法小遊戲。

線上試玩：<https://tlc-cmyk.github.io/bow-star/>

## 點玩

1. 打開 `index.html`（或上面嘅 GitHub Pages 連結），撳「開始」。
2. 用手指（或滑鼠）撳住畫面入面**發亮嘅弦**，沿琴弓**左右拖動**。
3. 每個音都有指定嘅弦（G／D／A／E）。拉啱、弓速適中，音色就會乾淨。
4. **太慢**會沙啞刮弦，**太快**會又尖又薄，**拉錯弦**個音會跳過。
5. 弓毛長度有限。拉到弓尖或者弓根之前，要**掉轉方向**先可以繼續樂句。掉轉時機就係呢隻遊戲嘅技巧。
6. 拉完《一閃一閃》全曲會得到評級：名演／普通／貓鬥架。

標題畫面同遊戲入面都有靜音掣。桌面瀏覽器用滑鼠一樣可以玩；手機請直立持機。

## 操作一覽

| 操作 | 作用 |
| --- | --- |
| 左右拖動琴弓 | 發聲、填滿而家嗰個音 |
| 撳住唔同嘅弦 | 換弦 |
| 拖到盡頭後反向拉 | 換弓（掉轉） |
| 「靜／聲」掣 | 靜音或開聲 |

## 技術

- 單資料夾靜態網頁：`index.html`、`style.css`、`audio.js`、`game.js`，無外部 CDN。
- 畫面用 Canvas 即場繪製（原創小提琴同琴弓美術）。
- 聲音用 Web Audio（震盪器、噪音同濾波器）合成：乾淨音、沙啞刮聲、尖細聲都唔靠取樣檔。
- 曲調係公眾領域兒歌《Twinkle Twinkle Little Star》（一閃一閃小星星）C 大調旋律。

## 本機開啟

用任何靜態伺服器都可以，例如：

```bash
cd bow-star
python3 -m http.server 8080
```

然後用手機或電腦瀏覽器打開提示嘅位址。直接用檔案協議打開 `index.html` 通常都可以玩（無需建置步驟）。
