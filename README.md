# 弓弦星

用弓拉《一閃一閃》、《兩隻老虎》、《歡樂頌》同《校歌》——一隻喺瀏覽器即玩、以手機直立為主嘅小提琴弓法小遊戲。跟住拍子即場拉，左手會自動按音。

線上試玩：<https://tlc-cmyk.github.io/bow-star/>

## 點玩

1. 打開 `index.html`（或上面嘅 GitHub Pages 連結），喺標題畫面揀班別（1A 至 6D）同學號（1 至 40），再揀一關。會先有四拍預備拍子。標題同結果畫面會顯示公開排行榜第 1 至 20 名（分數以演奏分百分比同曲目並列，例如 97.3%　一閃一閃）。
2. 用手指（或滑鼠）撳住下半部嘅琴面：**左右**拖動就係拉弓，**上下**握弦（上 E、再 A、再 D、最下 G）。兩條弦交界可以同時發聲。
3. 左手按音係自動嘅，唔使自己揀指法。只要跟住譜面由右向左行過嚟嘅音符，喺正確嘅弦、用適中嘅弓速拉。
4. **拉得太慢或太快**都會走音（太慢偏低、太快偏高），**拉錯弦**個音會跳（通常跳五度），但樂曲唔會停、亦唔會跳過嗰個音。
5. 弓毛長度有限（由弓根到弓尖）。拉到盡頭仲要再行，弓就拉唔郁，發唔到聲。最好喺**音符開頭**掉轉方向；音符中間突然掉轉會「嘎」一聲。
6. 畫面右上角嘅「演奏分」係即時分數。拉完會見到呢次嘅演奏痕跡，同評級。

標題、演奏同結果畫面都有靜音掣。桌面瀏覽器用滑鼠一樣可以玩；手機請直立持機。

## 操作一覽

| 操作 | 作用 |
| --- | --- |
| 左右拖動 | 拉弓（弓速影響音色同分數） |
| 上下位置 | 握弦（E／A／D／G，近交界會雙弦） |
| 喺音符開頭掉轉 | 乾淨換弓 |
| 喺音符中間掉轉 | 頓弓（嘎） |
| 「聲音：開／關」 | 靜音或開聲 |

## 評級（名演度）

| 名演度 | 評級 |
| --- | --- |
| 97 或以上 | 神技 |
| 90 或以上 | 名演 |
| 75 或以上 | 發表會 |
| 50 或以上 | 練習緊 |
| 25 或以上 | 滋擾街坊 |
| 其餘 | 噪音 |

低於 90 分時，結果畫面會用最大嘅字標示呢次最明顯嘅問題類型（例如鋸木、漏風、隔籬弦、雙弦、打嗝、無聲），而唔係評級名稱。如果破咗自己嘅最佳紀錄，會顯示「自我最佳更新」。

## 樂曲

前三首旋律屬於公眾領域（public domain），由本遊戲自行記譜；第四關《校歌》係按世界龍崗學校劉皇發中學官方樂譜全新記譜嘅旋律。伴奏全部係原創嘅簡單鋼琴和聲（I–IV–V）。四拍預備之後先入曲。

- 第一關《一閃一閃》（Twinkle Twinkle Little Star）：A 大調，104 BPM，喺 A 弦同 E 弦上拉。指法跟隨常見嘅鈴木教材第一冊演奏習慣；呢個調性同指法係公開嘅演奏實踐，並非從任何網站抄嚟嘅程式。
- 第二關《兩隻老虎》（Frère Jacques）：A 大調，108 BPM，同樣主要喺 A 弦同 E 弦。
- 第三關《歡樂頌》（貝多芬《歡樂頌》主題）：D 大調，100 BPM，引入 D 弦，並用空弦 A。
- 第四關《校歌》：F 大調，96 BPM，用齊 G、D、A、E 四條弦。旋律按學校官方出版樂譜自行記譜，並非複製任何 MIDI 或錄音；鋼琴伴奏係原創嘅 F 大調 I–IV–V 寫法。官方錄音同歌詞樂譜圖像唔收錄喺本專案。

## 技術

- 單資料夾靜態網頁：`index.html`、`style.css`、`engine.js`、`audio.js`、`game.js`，無建置步驟、無外部 CDN。
- 畫面用 Canvas 即場繪製（原創俯視小提琴同橫放琴弓；譜面同琴墊用淺色紙質風格）。
- 聲音用 Web Audio（震盪器、噪音同濾波器）合成，唔靠取樣檔。
- 玩法邏輯集中喺 `engine.js`，可以用 Node 做無介面測試：

```bash
node test-engine.mjs
```

測試會檢查：正確弦、中段弓速、只喺音符開頭掉轉，應該得到高名演度；完全唔郁應該接近 0 分而且無聲；拉錯弦會累積錯弦時間，但唔會跳過音符；名稱須為班別 1A 至 6D 加學號 1 至 40（例如 1A01、6D40），四關 song_key（twinkle／tigers／joy／school）都可以上載同顯示，公開排行榜唔會只篩校歌，並按分數同較早時間排序只取頭 20 名。單元測試唔會依賴網絡。

## 本機開啟

用任何靜態伺服器都可以，例如：

```bash
cd bow-star
python3 -m http.server 8080
```

然後用手機或電腦瀏覽器打開提示嘅位址。直接用檔案協議打開 `index.html` 通常都可以玩（無需建置步驟）。
